# Web App Requirements

Build a simple practice-test web app.

Preferred stack:

```text
Next.js
TypeScript
Tailwind CSS
Local JSON files
LocalStorage
```

## Pages

1. Home page
2. Test selection page
3. Test-taking page
4. Results page
5. Review page

## Test-taking behavior

Before submission:

- Show one question at a time
- Show answer options
- Allow previous and next navigation
- Allow answer changes
- Allow flagging for review
- Show timer
- Hide correct answers
- Hide explanations

After submission:

- Show total score
- Show percentage score
- Show correct / incorrect count
- Show domain breakdown
- Show difficulty breakdown
- Show explanations
- Show why each wrong answer is wrong

## Persistence

Use LocalStorage for:

- Selected answers
- Flagged questions
- Test progress
- Submitted results

A database is not needed for V1.
