# Question Quality Rules

Every question must pass these checks:

1. It maps to a syllabus topic.
2. It has one clear best answer unless marked as multiple-answer.
3. Distractors are plausible but wrong.
4. The explanation teaches the concept.
5. The wording is clear and exam-like.
6. It does not copy real CISSP exam questions.
7. It does not claim to be official CISSP content.
8. It does not repeat another question too closely.
9. It tests understanding, not just memory.
10. It has a difficulty label.

## Strong question pattern

A strong CISSP-style question usually asks what is:

- BEST
- MOST appropriate
- FIRST
- PRIMARY
- MOST important
- LEAST acceptable

But do not overuse these words mechanically.

## Weak question pattern

Avoid questions that only ask:

- What does this acronym mean?
- Which definition is correct?
- Which tool does X?
- Which port does X use?

Use direct knowledge questions only when the topic requires it.
